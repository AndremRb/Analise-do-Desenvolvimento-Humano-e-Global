# Análise do Desenvolvimento Humano e Econômico Global

Este projeto tem como objetivo realizar uma análise exploratória de dados globais utilizando o conjunto de dados Gapminder, fanzendo investigações e relacionando indicadores de desenvolvimento humano, economia, saúde e entre outros. O trabalho busca identificar padrões, tendências e possíveis correlações por meio de análises estatísticas e visualizações de dados, com a possibilidade de integrar fontes complementares.
